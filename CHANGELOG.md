# Changelog

## UNRELEASED

### Features
- Adds support for parsing conditional directives in VHDL
- Adds new `orbit clean` subcommand to remove artifacts generated by Orbit in the past
  
### Changes
- Build and test subcommands no longer allow for a `--keep` option; Orbit will always retain any existing contents during the planning phase from past builds/tests
  - See `orbit clean` for removing artifacts of past builds/tests
- Removes `default-` prefix in multiple configuration field names to be more consistent as it already is implied these are default values

### Fixes
- Fixes bug when a project's lockfile with no relative dependencies failed to automatically synchronize with the manifest during a local install of a project
- Fixes behavior for setting environment variables in a `config.toml` as relative paths to properly result in an absolute path one directory above the definition of the `config.toml`
- Fixes `orbit env` to display the correct values for environment variables (including those found in `config.toml` files under the `[env]` table)
- Improves error messages around the `orbit doc` command when trying to open the generated documentation using `--open`
- Correctly generates documentation for projects that have nested relative dependencies
- Filters out testbenches from the hardware graph during the planning phase for build mode (`orbit build`) when the top is left unspecified (collecting design hierarchies)

## 0.28.1

### Changes
- Updates `orbit get` JSON output to include all related source files (primary and secondary) for a given unit (primary file is always first in the list)

### Fixes
- JSON blueprints now correctly have a primary design unit file listed as a dependency of any of its corresponding sub unit files
- Correctly synchronizes a project's lock file using its manifest if a direct dependency previously was specified with a relative path but no longer uses a relative path

- Reverts `repository` field back to `source` to be more consistent with its intended usage and flexible functionality

- Removes rendundant lockfile saving when running `orbit build` and `orbit test` commands
